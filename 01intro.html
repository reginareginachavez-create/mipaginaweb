BREVE HISTORIA DE HTML

HTML fue creado por Tim Berners-Lee en 1991 para compartir información mediante Internet. Su primera versión permitía organizar textos, enlaces y documentos de forma sencilla. En 1995 surgió HTML 2.0, estableciendo un estándar para los navegadores web. Con los años aparecieron nuevas versiones, como HTML 4.01 y posteriormente HTML5. Actualmente, HTML5 es fundamental para crear y estructurar páginas web.
