Lista de Definiciones

Glosario de Términos Web

HTML
Lenguaje de marcado utilizado para estructurar páginas web.
CSS
Lenguaje de diseño utilizado para dar estilo y formato a los elementos web.
JavaScript
Lenguaje de programación orientado a dar interactividad a los sitios web.
Navegador
Software utilizado para acceder y visualizar páginas en Internet.
Servidor
Equipo informático encargado de almacenar y procesar datos para enviarlos a los clientes.
URL
Dirección única que identifica una página o recurso en la red.
HTTP
Protocolo de transferencia de hipertexto usado en la comunicación web.
Atributo
Valor adicional colocado dentro de una etiqueta HTML para modificar su comportamiento.
Etiqueta
Elemento básico de HTML usado para delimitar y definir contenido.
Base de Datos
Sistema organizado para almacenar, gestionar y recuperar información.
